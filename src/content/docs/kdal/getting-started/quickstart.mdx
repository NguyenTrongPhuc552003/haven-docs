This guide walks you through creating, compiling, and running a KDAL driver
from scratch.

## Prerequisites

- KDAL SDK installed ([Installation Guide](../installation/))
- `kdalc` and `kdality` on your PATH

## Your First Driver

<Steps>

1. **Scaffold a new project:**

   ```sh
   kdality init hello_led --class gpio
   cd hello_led
   ```

   This creates:

   ```
   hello_led/
   ├── hello_led.kdh          # Device header
   ├── hello_led_driver.kdc   # Driver code
   ├── Makefile               # make compile, make module
   └── README.md              # Notes
   ```

   The generated files already build: `make compile` works before you
   change anything.

2. **Edit the device header** (`hello_led.kdh`):

   ```kdal
   kdal_version: "0.1";

   device class HelloLed {
       compatible "example,hello-led";
       class gpio;

       registers {
           CTRL  : u32 @ 0x00 rw = 0x00;
           STATE : u32 @ 0x04 ro;
       }

       signals {
           toggle : in edge(rising);
       }

       power {
           on  : allowed;
           off : allowed;
           default : on;
       }
   }
   ```

3. **Implement the driver** (`hello_led_driver.kdc`). The header is
   imported under a name (`LED`), and every register and signal is
   reached through it:

   ```kdal
   kdal_version: "0.1";

   import "hello_led.kdh" as LED;

   driver HelloLedDriver for LED.HelloLed {

       probe {
           write(LED.CTRL, 0x01);
           log("hello_led: initialized\n");
       }

       remove {
           write(LED.CTRL, 0x00);
           log("hello_led: removed\n");
       }

       on read(LED.STATE) {
           wait(LED.toggle, 1000);
       }

       on write(LED.CTRL, val) {
           write(LED.CTRL, val);
       }

       on signal(LED.toggle) {
           let current = read(LED.STATE);
           if (current == 0x01) {
               write(LED.CTRL, 0x00);
           } else {
               write(LED.CTRL, 0x01);
           }
       }

       on power(on -> off) {
           write(LED.CTRL, 0x00);
       }

       on power(off -> on) {
           write(LED.CTRL, 0x01);
       }
   }
   ```

4. **Lint the sources:**

   ```sh
   kdality lint hello_led.kdh
   kdality lint hello_led_driver.kdc
   ```

5. **Compile to kernel C:**

   ```sh
   make compile        # runs: kdality compile hello_led_driver.kdc -o output
   ```

   This produces:

   - `output/HelloLedDriver.c` - the kernel module source (named after the driver)
   - `output/Makefile.kbuild` - Kbuild Makefile for `make modules`

6. **Build the kernel module:**

   ```sh
   make module KDIR=/path/to/kernel/build
   ```

7. **Load it in QEMU:**

   ```sh
   cp output/HelloLedDriver.ko /path/to/shared/
   # Inside the QEMU guest:
   insmod /mnt/modules/HelloLedDriver.ko
   ```

</Steps>

## Simulating Without a Kernel

You can dry-run your driver without building a kernel module:

```sh
kdality simulate hello_led_driver.kdc
```

This runs an interpreter that traces register reads/writes to stdout.

## Generating Tests

Auto-generate KUnit test stubs from your driver:

```sh
kdality test-gen hello_led_driver.kdc -o tests/   # writes tests/test_HelloLedDriver.c
```

## Generating Device Tree Overlays

If your target uses Device Tree:

```sh
kdality dt-gen hello_led.kdh -o dts/       # writes dts/HelloLed.dtso
```

<Aside type="note">
  The compiler is at v0.1.0-alpha. `kdality compile` does not read the
  imported header yet: register names reach the generated C as written, so
  run `kdality lint`, which does read it. See the
  [Language Specification](../../language/spec/) for the full grammar.
</Aside>
